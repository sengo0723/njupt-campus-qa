# 数据与隔离

冻结快照日期为 2026-10-26。资料来自南京邮电大学官方公开网站，五类有效资料分别为 12、8、12、12、12 份，共 56 份。

- `processed/documents.jsonl`：冻结清洗正文、表格、页码、来源、日期及校验值；原始 HTML/PDF 不在 Git 中。
- `corpus_manifest.json`：资料与哈希；采集入口在 `../config/sources.json`。
- `sft/`：1200 训练、150 验证、150 测试，messages JSONL 和独立 provenance。训练用途配额为稳定知识 200、证据作答 500、拒答 200、时效多轮 150、表格计算 150。
- `eval/`：20 道开发、80 道固定测试、四道单列验收题及 24 道计算专项。
- `sft_aligned*`：后续对齐数据；rich-long 已准备而未正式训练。
- `tuning/`：核验事实、注释、验证和另冻结最终新题。最终新题未用于候选选优。

初版共 624 条标记的合成练习，不代表学校政策，不进入 RAG。训练主要由原文抽取、受控模板与程序计算构造，并非逐条人工标注的自然问答。

初版事实组 ID 交集为零，但不同网页仍会复述学校精神和创办年份，不能声称所有校园正例为未见事实。详见 `../experiments/2026-10-26/tuning/isolation_review.json`，后续对齐版加强隔离。

原文、摘录与衍生问答中的第三方权利仍归原权利人，代码 MIT 许可不覆盖这些权利。保留来源以便核验，项目无学校官方背书。历史流程按所引年份解释，采集日期不等同于政策生效日期。采集应遵守站点规则与频率限制。

刷新采集或重建数据会改变快照及哈希，不可沿用冻结指标作为新配置成绩。恢复原文件见 `../docs/REPRODUCING.md`。
