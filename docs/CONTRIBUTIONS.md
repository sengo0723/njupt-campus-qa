# 分工与贡献

项目负责人设计第一版独立 SFT 训练链路与 RAG 检索链路，包括资料与训练样本的用途、训练和验证流程、模型部署衔接、检索与证据组织，以及统一问答接口。负责人另承担系统架构、RAG 工程实现、FastAPI、React 网页、计算工具、集成验收和交付。

成员一在初版链路上负责部署调试、推理参数核验、RAG 使用评测、日志排查和 bug 定位。

成员二负责爬虫与清洗、数据集整理、badcase 分析和后续调优维护。旧 checkpoint、学习率和证据对齐等属于后续优化。首版 SFT 与 RAG 设计不计入两位成员的原创设计贡献。

实验日志描述项目实际运行，不以脚本中出现某模块来推断个人作者。未执行续训、KL 正则正式训练及提前停止候选均不列为完成成果。
