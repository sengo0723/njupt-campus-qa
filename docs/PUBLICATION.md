# 公开材料说明

本仓库由完整本地实验副本整理，公开源码、配置、锁文件、清洗正文、SFT 与评测数据、历史实验输出和界面截图。历史材料保存于 experiments/2026-10-26，运行输出另写 results。

公开时排除全部模型权重与 adapter、Python/Node 环境、会话数据库、聊天追踪、进程状态、服务日志、原始学校 HTML/PDF、个人实验报告和课程任务书附件。原文通过来源清单按需获取。

历史记录中的本机项目路径改为字面量 ${PROJECT_ROOT}，缓存路径改为 ${HF_HOME}，不改问答、loss、指标、模型 digest 或原始运行日期。因此被替换路径的 JSON 文件哈希会不同；历史 reproducibility.json 中的哈希描述原始实验产物，不能用于验证公开版改过的源码。公开版文件哈希见 PUBLICATION_MANIFEST.json。

初版句子分组的语义重复局限、负迁移及停止调优状态保留。源代码发布后的可移植性修复不构成重新训练，也不改变已公开的历史成绩。
